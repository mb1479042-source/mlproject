# AI-Driven E-Commerce Customer Segmentation Engine

An end-to-end Machine Learning web application that uses RFM (Recency, Frequency, Monetary) analytics and K-Means Clustering to classify e-commerce customers into actionable target segments.

## 🚀 Features
- **RFM Feature Engineering:** Computes data metrics directly from raw online retail transaction data.
- **Machine Learning Pipeline:** Implements Scikit-Learn's K-Means clustering with optimal preprocessing (Log transformation + Standard Scaling).
- **Interactive UI Dashboard:** Built with Streamlit to allow marketing analysts to enter customer metrics and fetch immediate tier predictions alongside data-driven conversion strategies.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Libraries:** Pandas, NumPy, Scikit-Learn, Joblib, NLTK
- **UI Framework:** Streamlit
